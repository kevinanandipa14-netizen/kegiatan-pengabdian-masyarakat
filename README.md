# Penguatan Nilai Sila ke-2 Pancasila — SDIT Raflesia Depok

Website dokumentasi kegiatan Pengabdian kepada Masyarakat UBSI. Dibuat dengan HTML, CSS, dan JavaScript murni agar mudah dipublikasikan melalui GitHub Pages.

## Isi repository
- `index.html` — halaman utama
- `style.css` — tampilan responsif
- `script.js` — navigasi mobile
- `assets/` — foto, poster, peta, grafik, dan logo yang diekstrak dari dokumen laporan

## Menjalankan secara lokal
Buka `index.html` di browser, atau jalankan server lokal sederhana.

## Publikasi ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `pkm-sdit-raflesia-depok`.
2. Unggah seluruh isi folder ini (bukan folder pembungkusnya) ke branch `main`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment dan buka URL GitHub Pages yang diberikan.

## Catatan kelengkapan konten
- Foto yang tersedia saat ini diekstrak dari dokumen laporan: foto guru, foto siswa belajar, peta, grafik observasi, dan poster.
- Lampiran dokumentasi foto pelaksanaan pada dokumen laporan masih kosong.
- Dokumen yang diunggah ke percakapan ini adalah DOCX laporan, bukan PDF naskah video. Bagian video masih menunggu naskah/tautan video agar dapat diisi sesuai sumber.
- Data hasil observasi ditampilkan sebagai ringkasan sebagaimana dilaporkan, bukan evaluasi individual.
